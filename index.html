먼저 답: Orca로 할 수 있는 것 7가지

1. 혈액검사 웹앱을 어디까지 자동 개발?

상당 부분 가능합니다.

가능한 것
화면 생성, 입력폼, 결과표, 파일 업로드, 모바일 UI, 테스트, 수정 반복

직접 정해야 하는 것
의학적 판정 기준, 모듈 구조, 최종 판단 로직

2. Claude Code와 Codex는 어떻게 나눌까?

역할을 나눠 쓰면 가장 편합니다.

Claude Code = 큰 구조, UI, 긴 수정
Codex = 코드 검토, 버그, 테스트, 리팩터링

3. Netlify 자동배포 가능?

가능합니다.

GitHub에 push → Netlify가 자동 빌드/배포
preview 배포와 production 배포를 나눠서 운영 가능

4. OCR 테스트 자동화도 가능?

가능합니다.

검사표 업로드 → OCR 결과 확인 → 잘못 읽은 값 수정 → 다시 테스트
이 반복 과정을 Orca에서 agent에게 맡길 수 있습니다.

5. Cursor 대신 Orca?

완전 대체라기보다 상위 지휘실에 가깝습니다.

Cursor가 편한 코딩 툴이라면 유지하고
Orca를 여러 agent를 동시에 돌리는 본부로 쓰는 방식이 좋습니다.

6. 브라우저 자동화 / 정기 실행?

가능합니다.

버튼 클릭, 폼 입력, 화면 확인, 반복 테스트 같은 작업을 자동화하고
정기 실행 구조도 설계할 수 있습니다.

7. Windows 11 미니PC 상시 운용?

가능합니다.

미니PC를 개발 기지처럼 써서
Orca + Claude + Codex + GitHub + Netlify 흐름을 상시 운영할 수 있습니다.

한 줄 요약

Orca는 코딩앱이라기보다 AI 직원들을 부리는 작업실입니다.

내 역할: 목표와 기준 제시
Orca 역할: 에이전트 실행, 분기, 비교, 테스트, 화면 확인

첫 퀘스트에 바로 쓸 프롬프트

아래 문장을 Claude Code에 그대로 넣으면 혈액검사 판독 웹앱 V0.1 시작용으로 적당합니다.

혈액검사 판독 웹앱 V0.1을 만들어라. React 기반으로 시작하고 Netlify 배포를 고려해라. 우선 기능은 3개만 구현해라. 1) 검사항목 직접 입력 2) 표준 참고범위 기반 이상 여부 표시 3) 결과 화면 출력 대상 항목은 CBC, CMP, thyroid 일부 항목으로 시작해라. 모바일에서도 보기 쉽게 만들어라. 추후 OCR과 모듈 구조를 붙일 수 있도록 폴더 구조를 깔끔하게 설계해라. 디자인은 깔끔한 의료 대시보드 스타일로 해라.
